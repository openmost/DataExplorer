# DataExplorer

## Description

Explore your Matomo data the way you would in GA4 Explorations, or write guarded raw SQL on the Matomo tables, then save, share and export the result.

### Features

- **Free-form explorer**: pick dimensions, metrics and a period, preview the table and the chart, with the same limits whatever the size of your database.
- **Guarded raw SQL** for super users: read-only queries, a row limit, an execution time limit, a cache and a list of tables that can never be queried.
- **Saved explorations** with the standard Matomo permissions, and exports.
- **Limits you control**: row limits, execution time, cache and invalidation period are set in the `[DataExplorer]` section of `config/config.ini.php`.
- Translated into 12 languages.

### Requirements

Matomo 5+.
